# 一体化企业管理系统架构设计文档

## 1. 系统概述

### 1.1 项目背景
本项目旨在构建一个集成客户管理、项目管理、员工管理、财务管理等功能的一体化企业管理平台，支持PC端、移动端等多端访问，为企业提供全方位的数字化管理解决方案。

### 1.2 设计目标
- **统一管理**：实现客户、项目、员工、财务等业务的一体化管理
- **多端适配**：支持PC Web端、移动端APP、管理后台等多种访问方式
- **高可用性**：微服务架构，支持水平扩展和容错处理
- **安全性**：完善的权限控制体系和数据安全保障
- **可扩展性**：模块化设计，支持业务功能快速扩展

### 2.2 技术架构

#### 2.2.1 前端技术栈
- **PC Web端**：Vue 3 + TypeScript + Ant Design Pro + Vite
- **移动端**：React Native + TypeScript + Redux Toolkit
- **管理后台**：Ant Design Pro + React 18 + TypeScript
- **公共组件**：Storybook + Tailwind CSS

#### 2.2.2 后端技术栈
- **基础框架**：Spring Boot 3.x + Spring Cloud Alibaba 2022.x
- **服务注册**：Nacos 2.x (服务注册与发现)
- **配置中心**：Nacos Config (统一配置管理)
- **服务网关**：Spring Cloud Gateway (路由、限流、认证)
- **分布式事务**：Seata 1.x (AT模式)
- **熔断限流**：Sentinel (服务保护)
- **消息队列**：RocketMQ 5.x (异步解耦)
- **数据库**：MySQL 8.0 (主从集群)
- **缓存**：Redis 7.0 (集群模式)
- **搜索引擎**：Elasticsearch 8.x (全文检索)
- **文件存储**：MinIO (对象存储)

#### 2.2.3 DevOps工具链
- **容器化**：Docker + Docker Compose + Kubernetes
- **CI/CD**：Jenkins / GitLab CI
- **监控告警**：Prometheus + Grafana + AlertManager
- **日志系统**：ELK Stack (Elasticsearch + Logstash + Kibana)
- **API文档**：Swagger + OpenAPI 3.0
- **代码质量**：SonarQube

## 5. 权限设计

### 5.1 RBAC权限模型

```
用户(User) -> 角色(Role) -> 权限(Permission) -> 菜单(Menu) -> API接口(API)
    ↑           ↑              ↑               ↑            ↑
   部门        角色组         权限组          菜单分组      接口分组
```

### 5.2 权限控制策略

#### 5.2.1 前端路由权限

```typescript
// router/index.ts
const routes: RouteRecordRaw[] = [
  {
    path: '/admin',
    component: Layout,
    meta: {
      roles: ['admin'],
      permissions: ['system:manage']
    },
    children: [
      {
        path: 'users',
        component: () => import('@/views/admin/UserList.vue'),
        meta: {
          title: '用户管理',
          permissions: ['user:list', 'user:create', 'user:edit', 'user:delete']
        }
      }
    ]
  }
]

// 权限守卫
router.beforeEach((to, from, next) => {
  const userStore = useUserStore()
  const hasPermission = userStore.hasPermission(to.meta.permissions)

  if (hasPermission) {
    next()
  } else {
    next('/403')
  }
})
```

#### 5.2.2 后端API权限

```java
@PreAuthorize("hasAuthority('user:list')")
@GetMapping("/users")
public Result<List<UserVO>> listUsers(UserQueryDTO query) {
    List<UserVO> users = userService.listUsers(query);
    return Result.success(users);

@PreAuthorize("@permissionService.hasPermission('user', 'create')")
```

### 5.3 数据权限控制

```java
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface DataPermission {
    /**
     * 数据范围类型：ALL全部、DEPT部门、SELF个人
     */
    String scope() default "SELF";

    /**
     * 数据权限字段，如dept_id
     */
    String field() default "dept_id";
}

@DataPermission(scope = "DEPT", field = "dept_id")
@GetMapping("/users")
public Result<List<UserVO>> listUsers() {
    // 自动添加数据权限过滤条件
    List<UserVO> users = userService.listUsers();
    return Result.success(users);
}
```

```java
@Aspect
@Component
public class SqlInjectionAspect {

    @Around("execution(* com.company.*.mapper.*.*(..))")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        Object[] args = joinPoint.getArgs();
        for (Object arg : args) {
            if (arg instanceof String) {
                String param = (String) arg;
                if (containsSqlInjection(param)) {
                    throw new SecurityException("检测到SQL注入风险");
                }
            }
        }
        return joinPoint.proceed();
    }

    private boolean containsSqlInjection(String input) {
        String[] sqlKeywords = {"'", ";", "--", "/*", "*/", "xp_", "exec", "select", "insert", "update", "delete", "drop"};
        for (String keyword : sqlKeywords) {
            if (input.toLowerCase().contains(keyword)) {
                return true;
            }
        }
        return false;
    }
}
```

```java
@Component
```

```java
    @Autowired
    private Tracer tracer;

    @Around("@annotation(trace)")
    public Object around(ProceedingJoinPoint joinPoint, Trace trace) throws Throwable {
        String operationName = trace.operationName().isEmpty() ?
            joinPoint.getSignature().getName() : trace.operationName();

        Span span = tracer.buildSpan(operationName).start();
        try {
            return joinPoint.proceed();
        } catch (Exception e) {
            span.setTag("error", true);
            span.log(Map.of("event", "error", "error.object", e));
            throw e;
        } finally {
            span.finish();
        }
    }
}
```

#### 10.1.2 多级缓存

```java
@Service
public class UserService {

    @Autowired
    private UserMapper userMapper;

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Cacheable(value = "users", key = "#id")
    public UserVO getUserById(Long id) {
        // 先查本地缓存
        UserVO user = LocalCache.get("user:" + id);
        if (user != null) {
            return user;
        }

        // 再查Redis
        String redisKey = "user:" + id;
        user = (UserVO) redisTemplate.opsForValue().get(redisKey);
        if (user != null) {
            LocalCache.put("user:" + id, user, Duration.ofMinutes(5));
            return user;
        }

        // 最后查数据库
        User userEntity = userMapper.selectById(id);
        user = UserConvert.convertToVO(userEntity);

        // 写入缓存
        LocalCache.put("user:" + id, user, Duration.ofMinutes(5));
        redisTemplate.opsForValue().set(redisKey, user, Duration.ofHours(1));

        return user;
    }
}
```
